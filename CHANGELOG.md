# Changes

## 2.0.2

- Fix automatic launch when macOS reports the helper as not found.
- Register the embedded launcher with Launch Services before ServiceManagement.
- Use an embedded login item and show registration status, heartbeat and errors.
- Automatic launch confirmed by the user on their setup.
- Cross-version macOS behavior remains dependent on local authorization.


## 2.0

- New glass-and-metal TC icon.
- Graphical setup with progress, success and error details.
- Installation replaces the existing app and stops the utility's helper.
- Optional reset of the utility's Screen Recording authorization.
- Links to the relevant macOS privacy and background settings.
- Optional launch and quit with Resolve, including the Project Manager.
- Saved capture areas, preview, window position and capture-rate settings.
- Separate background launcher with no screen or audio capture code.
- Ad-hoc signed universal build for macOS 14 or later.

## 1.6.13

Initial public release with three readouts, local OCR, settings and
saved window placement.
